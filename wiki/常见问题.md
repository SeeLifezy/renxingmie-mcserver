# 常见问题

本页收录服务端使用中的常见问题与解决方法。

---

## 启动问题

### Q: 双击 `run.bat` 闪退

**A:** 可能原因：

1. 未安装 Java 17，或 JAVA 版本不正确
   - 解决：安装 [Java 17](https://adoptium.net/temurin/releases/?version=17)
2. 路径含特殊字符
   - 解决：将服务端移动到纯英文路径
3. 内存不足
   - 解决：编辑 `run.bat`，降低 `-Xmx` 值

### Q: 提示 "Error: could not open server.properties"

**A:** 文件被其他程序占用。关闭文本编辑器后重试。

### Q: 启动后立即崩溃

**A:** 检查 `logs/latest.log` 末尾的报错信息。常见原因：

- Java 版本错误（需 17，不能用 8/11/21）
- 内存不足
- mods 文件损坏

## 连接问题

### Q: 客户端无法连接服务器

**A:** 排查步骤：

1. 确认服务器已启动（控制台显示 "Done"）
2. 确认 IP 与端口正确（默认 `25565`）
3. 确认防火墙未拦截端口
4. 确认 `server.properties` 中 `online-mode` 设置匹配客户端类型

### Q: 提示 "Failed to verify username"

**A:** 客户端为非正版，但服务器 `online-mode=true`。

解决：编辑 `server.properties`，将 `online-mode=true` 改为 `online-mode=false`，重启服务器。

### Q: 命令方块不工作

**A:** 确认 `server.properties` 中：

```
enable-command-block=true
```

## 游戏问题

### Q: 脚下不生成幸运方块

**A:** 输入指令开启：

```
/luckywalk true
```

关闭：

```
/luckywalk false
```

### Q: 服务器卡顿

**A:** 可能原因与优化：

1. 内存不足 → 提高 `-Xmx`
2. 玩家过多 → 调低 `view-distance`、`simulation-distance`
3. 模组过多 → 参考 [模组清单](wiki/模组清单)，禁用不必要的模组

### Q: 世界损坏

**A:** 使用 `重置地图/` 下的初始存档重置世界，详见 [启动指南](wiki/启动指南#重置世界)。

**A:** 服务端 ZIP 已包含全部模组。如需单独获取，请：

1. 下载完整 ZIP 包
2. 或参考 `manifest.json` 列出的模组清单，从 CurseForge / Modrinth 下载
