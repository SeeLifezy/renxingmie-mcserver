# 脚下随机生成幸运方块服务端

> 专属页面：本服务端特有的指令与玩法说明。
> MC 版本：**1.20.1 Forge 47.3.3**  |  Java：**17**
> 下载：[Releases - luckywalk-v1.0](https://github.com/SeeLifezy/renxingmie-mcserver/releases/tag/luckywalk-v1.0)

---

## 简介

走路时脚下会随机生成幸运方块的空岛玩法服务端。

## 专属指令

本服务端独有 `/luckywalk` 指令（其他服务端没有此指令）：

| 指令 | 说明 |
|------|------|
| `/luckywalk true` | 开启脚下随机生成幸运方块 |
| `/luckywalk false` | 关闭脚下随机生成幸运方块 |

## 玩前必看

- 开启后行走时脚下会不断生成幸运方块，注意及时清理
- 本玩法基于 `randomly_generate_lucky_blocks` 模组实现

## 环境要求

| 项目 | 要求 |
|------|------|
| Minecraft 版本 | 1.20.1 |
| 模组加载器 | Forge 47.3.3 |
| Java 版本 | Java 17 |

通用启动步骤见 [启动指南](启动指南)。
