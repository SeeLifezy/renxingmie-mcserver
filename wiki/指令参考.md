# 指令参考

本页列出服务端内可用的关键指令。

> 大部分指令需要 OP 权限（`op-permission-level=4`）。

---

## 脚下随机生成幸运方块

`/luckywalk` 指令**仅限"脚下随机生成幸运方块"服务端**，详见专属页面：[脚下随机生成幸运方块](脚下随机生成幸运方块)

---

## 服务器管理

| 指令 | 说明 |
|------|------|
| `/op <玩家>` | 给予管理员权限 |
| `/deop <玩家>` | 移除管理员权限 |
| `/kick <玩家>` | 踢出玩家 |
| `/ban <玩家>` | 封禁玩家 |
| `/whitelist add <玩家>` | 添加白名单 |
| `/stop` | 安全关闭服务器 |

---

## WorldEdit 世界编辑

| 指令 | 说明 |
|------|------|
| `//wand` | 获取选区工具 |
| `//pos1` `//pos2` | 设置选区点 |
| `//set <方块>` | 将选区设为指定方块 |
| `//copy` | 复制选区 |
| `//paste` | 粘贴 |
| `//undo` | 撤销 |
| `//redo` | 重做 |

---

## Lucky Block 幸运方块

| 指令 | 说明 |
|------|------|
| `/luckyblock give <玩家> <数量>` | 给予幸运方块 |
| `/luckyblock gen <x> <y> <z>` | 在指定位置生成幸运方块 |

> 具体指令以服务端集成的 Lucky Block 版本为准。

---

## 服务器配置指令

| 指令 | 说明 |
|------|------|
| `/gamemode <模式> <玩家>` | 切换游戏模式 |
| `/tp <玩家>` | 传送到玩家 |
| `/give <玩家> <物品> <数量>` | 给予物品 |
| `/time set <时间>` | 设置时间 |
| `/weather <类型>` | 设置天气 |
| `/difficulty <难度>` | 设置难度 |

---

## 命令方块

服务端已启用命令方块（`enable-command-block=true`），可用于：

- 自动化幸运方块生成
- 自定义游戏规则
- 红石电路逻辑扩展

获取命令方块：

```
/give @p command_block
```

---

*如需添加自定义指令，请参考对应模组的文档。*
