# 启动指南

本页介绍如何启动任性咩幸运方块服务端。

---

## 环境要求

| 项目 | 要求 |
|------|------|
| Minecraft 版本 | 1.20.1 |
| 模组加载器 | Forge 47.3.3 |
| Java 版本 | **Java 17**（必须） |
| 可用内存 | 至少 4 GB（推荐 6 GB+） |
| 操作系统 | Windows /  Linux |

### Java 17 下载

推荐 [Eclipse Temurin / Adoptium](https://adoptium.net/temurin/releases/?version=17)。

---

## 启动步骤

### 1. 下载服务端

前往 [Releases](https://github.com/SeeLifezy/renxingmie-mcserver/releases) 下载所需服务端的 ZIP 包。

### 2. 解压

将 ZIP 包解压到任意目录（路径建议不含中文与空格）。

### 3. 启动服务器

#### Windows
双击 `run.bat`，配置文件如下：

```bat
java -Xmx4G -Xms4G @libraries/net/minecraftforge/forge/1.20.1-47.3.3/win_args.txt %*
```

#### Linux / macOS
创建启动脚本 `run.sh`：

```bash
#!/usr/bin/env bash
java -Xmx4G -Xms4G @libraries/net/minecraftforge/forge/1.20.1-47.3.3/unix_args.txt "$@"
```

赋予执行权限并启动：

```bash
chmod +x run.sh
./run.sh nogui
```

> 说明：Linux/macOS 使用 `unix_args.txt`，对应 Windows 的 `win_args.txt`；`"$@"` 用于透传额外参数，例如 `nogui`。内存参数 `-Xmx4G -Xms4G` 可根据服务器配置调整。

---

#### 无 Java 环境变量时的配置

如果系统未配置 Java 环境变量（终端执行 `java -version` 提示命令未找到），需手动指定 Java 路径。

**方式一：临时设置环境变量（当前终端会话有效）**

```bash
export JAVA_HOME=/usr/lib/jvm/java-17-openjdk   # 根据实际安装路径修改
export PATH=$JAVA_HOME/bin:$PATH
./run.sh nogui
```

**方式二：修改 `run.sh`，使用完整 Java 路径**

先查找 Java 安装路径：

```bash
# Debian/Ubuntu 可用
update-alternatives --list java

# 或在常见目录搜索
find /usr/lib/jvm -name java -type f 2>/dev/null
```

然后修改 `run.sh`：

```bash
#!/usr/bin/env bash
JAVA="/usr/lib/jvm/java-17-openjdk/bin/java"   # 替换为实际路径
"$JAVA" -Xmx4G -Xms4G @libraries/net/minecraftforge/forge/1.20.1-47.3.3/unix_args.txt "$@"
```

再次赋予执行权限并运行：

```bash
chmod +x run.sh
./run.sh nogui
```

**方式三：脚本中自动检测 JAVA_HOME（推荐）**

```bash
#!/usr/bin/env bash
# 若未设置 JAVA_HOME，尝试常见路径
if [ -z "$JAVA_HOME" ]; then
    if [ -x "/usr/lib/jvm/java-17-openjdk/bin/java" ]; then
        JAVA_HOME="/usr/lib/jvm/java-17-openjdk"
    elif [ -x "/usr/lib/jvm/java-11-openjdk/bin/java" ]; then
        JAVA_HOME="/usr/lib/jvm/java-11-openjdk"
    else
        echo "未找到 Java，请设置 JAVA_HOME 环境变量或安装 Java。" >&2
        exit 1
    fi
fi

"$JAVA_HOME/bin/java" -Xmx4G -Xms4G @libraries/net/minecraftforge/forge/1.20.1-47.3.3/unix_args.txt "$@"
```

> 提示：Minecraft 1.20.1 通常需要 Java 17，请确保安装对应版本。如果 Java 安装在其他位置，请相应修改路径。

### 4. 阅读说明

启动前请阅读压缩包内的 `1启动前观看.txt`。

## 内存调整

编辑 `run.bat`，修改 JVM 参数：

```bat
java -Xmx4G -Xms4G @libraries/net/minecraftforge/forge/1.20.1-47.3.3/win_args.txt %*
```

| 参数 | 含义 | 建议 |
|------|------|------|
| `-Xmx4G` | 最大内存 | 8 GB 机器设 6G |
| `-Xms4G` | 初始内存 | 与 Xmx 一致 |

## 服务器配置

### `server.properties` 关键项

| 配置项 | 推荐值 | 说明 |
|--------|--------|------|
| `online-mode` | `true` / `false` | 正版验证；非正版客户端改为 `false` |
| `enable-command-block` | `true` | **必须开启**，命令方块用于幸运方块逻辑 |
| `max-players` | `10` | 最大在线人数 |
| `server-port` | `25565` | 服务器端口 |
| `motd` | 自定义 | 服务器列表显示信息 |

### 客户端连接

1. 安装 Minecraft 1.20.1 + Forge 47.3.3
2. 启动 Minecraft
3. 多人游戏 → 添加服务器 → 输入服务器 IP
4. 加入服务器

---

## 重置世界

如需重置世界到初始状态：

1. 停止服务器
2. 删除 `world/` 目录
3. 将 `重置地图/` 下的初始存档复制到 `world/`
4. 重新启动服务器
