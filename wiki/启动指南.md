# 启动指南

本页介绍如何启动任性咩幸运方块服务端。

---

## 环境要求

| 项目 | 要求 |
|------|------|
| Minecraft 版本 | 1.20.1 |
| 模组加载器 | Forge 47.3.3 |
| Java 版本 | **Java 17**（必须） |
| 可用内存 | 至少 4 GB（推荐 6 GB+） |
| 操作系统 | Windows / macOS / Linux |

### Java 17 下载

推荐 [Eclipse Temurin / Adoptium](https://adoptium.net/temurin/releases/?version=17)。

---

## 启动步骤

### 1. 下载服务端

前往 [Releases](https://github.com/SeeLifezy/renxingmie-mcserver/releases) 下载所需服务端的 ZIP 包。

### 2. 解压

将 ZIP 包解压到任意目录（路径建议不含中文与空格）。

### 3. 启动服务器

双击 `run.bat`（Windows）。

首次启动会自动生成世界与配置文件。

### 4. 阅读说明

启动前请阅读压缩包内的 `1启动前观看.txt`。

---

## 内存调整

编辑 `run.bat`，修改 JVM 参数：

```bat
java -Xmx4G -Xms4G @libraries/net/minecraftforge/forge/1.20.1-47.3.3/win_args.txt %*
```

| 参数 | 含义 | 建议 |
|------|------|------|
| `-Xmx4G` | 最大内存 | 8 GB 机器设 6G |
| `-Xms4G` | 初始内存 | 与 Xmx 一致 |

---

## 服务器配置

### `server.properties` 关键项

| 配置项 | 推荐值 | 说明 |
|--------|--------|------|
| `online-mode` | `true` / `false` | 正版验证；非正版客户端改为 `false` |
| `enable-command-block` | `true` | **必须开启**，命令方块用于幸运方块逻辑 |
| `max-players` | `10` | 最大在线人数 |
| `server-port` | `25565` | 服务器端口 |
| `motd` | 自定义 | 服务器列表显示信息 |

### 客户端连接

1. 安装 Minecraft 1.20.1 + Forge 47.3.3
2. 启动 Minecraft
3. 多人游戏 → 添加服务器 → 输入服务器 IP
4. 加入服务器

---

## 重置世界

如需重置世界到初始状态：

1. 停止服务器
2. 删除 `world/` 目录
3. 将 `重置地图/` 下的初始存档复制到 `world/`
4. 重新启动服务器
